PREREQUISITES:
  ✓ Node.js v16+ installed (https://nodejs.org/)
  ✓ Python 3.8+ installed (https://www.python.org/)
  ✓ ML_PriceCard.xlsm in project folder

================================================================================
STEP-BY-STEP SETUP (5 MINUTES)
================================================================================

1. OPEN TERMINAL IN PROJECT FOLDER
   Windows: Press Win+R, type: cmd
   Navigate to: C:\Users\JailR\OneDrive - MeridianLink\CPQ Project - 2026

2. INSTALL NODE DEPENDENCIES
   Command: npm install
   Wait for completion (2-5 minutes)

3. INSTALL PYTHON PACKAGES
   Command: pip install python-docx openpyxl
   Wait for completion (30-60 seconds)

4. CREATE .env FILE
   Create file: .env
   Copy this content:

   PORT=5000
   NODE_ENV=development
   PYTHON_PATH=python3
   EXCEL_FILE_PATH=./ML_PriceCard.xlsm

   (Leave Salesforce fields empty for MVP)

5. START THE SERVER
   Command: npm start

   Expected output:
   "CPQ Proposal Generator API running on port 5000"

6. OPEN IN BROWSER
   Go to: http://localhost:5000

   You should see the MeridianLink CPQ app

7. TEST IT
   • Enter customer name
   • Add a product
   • Select tier and year
   • Apply a discount
   • Click "Generate Proposal"
   • A Word document downloads

================================================================================
TROUBLESHOOTING
================================================================================

Error: "npm: command not found"
→ Node.js not installed. Download from https://nodejs.org/

Error: "python: command not found"
→ Python not installed. Download from https://www.python.org/

Error: "port 5000 already in use"
→ Another app using port 5000. Change PORT=5001 in .env

Error: "Excel file not found"
→ ML_PriceCard.xlsm missing. Copy to project folder.

Error: "Word generation failed"
→ Run: pip install --upgrade python-docx openpyxl
